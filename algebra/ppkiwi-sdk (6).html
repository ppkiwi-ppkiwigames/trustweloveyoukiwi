Set up Algebra

Algebra keeps the shared files in a public GitHub repo. To turn it on:
1. In Math Work, create a public repo (for example ppkiwi-algebra) with the README box ticked.
2. On GitHub go to Settings, Developer settings, Fine-grained tokens. Make a token for only that repo with Contents set to Read and write, and give it an expiry date.
3. In this file, find const ALGEBRA and fill in owner, repo and token. Save the file and reopen it.

Heads up: the token sits inside this file, so anyone who opens the file can read it. A token limited to that one repo can only change files in that repo, but don't use your main token here.
Everyone using ppkiwi sdk sees these files.

Upload files
